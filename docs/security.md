# Security boundaries

What the code protects, how, and which tests hold it in place. Report problems privately: see
[SECURITY.md](../SECURITY.md).

## Running it safely

- Configure working email delivery or a sign-in provider that verifies email ownership. Password
  login and library use work for unverified users; creating API keys and authorizing OAuth apps
  require a verified email.
- Set `TRUST_PROXY` to the exact address or subnet of your reverse proxy, and keep the web port
  reachable only through it. A wrong value can reject valid HTTPS form posts; never trust a range
  that includes untrusted clients.
- Keep S3-compatible buckets private. Images always pass through the app's owner-checked asset route.
- The container runs as UID 1000; volumes it writes must belong to UID and GID 1000.

See [docs/self-hosting](self-hosting/README.md) for the full setup.

## Dependencies

The latest stable parent packages still pulled vulnerable versions of esbuild and phin. Narrow overrides select esbuild `0.25.12` for `@esbuild-kit/core-utils` and phin `3.7.1` for `@jimp/core`. Migration generation/application, production builds and a local image-tracing smoke test check those integrations. Reassess the overrides when upgrading the parent packages.

CI runs `pnpm audit --audit-level moderate` in addition to lint, type checks, tests and builds. A clean dependency audit covers known advisories only.
