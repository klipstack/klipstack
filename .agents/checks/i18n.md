name: i18n
description: User-facing text exists in English and Spanish, never hard-coded
severity-default: medium
---

Klipstack's interface is in English and Spanish (`packages/i18n/src/locales/{en,es}`). Report:

- Text a user can see or hear written as a literal outside the JSX, where lint can't see it:
  strings in a variable, an array, a `meta` page title, an email, a toast, a `throw` that
  reaches the page. Lint (`klipstack/ui-text-translated`) refuses JSX text and literal
  `aria-label`, `title`, `alt` and `placeholder` attributes; judge each `oxlint-disable` of it
  the diff adds.
- Spanish that is not Spanish: a copy of the English, a placeholder. That both languages have the
  same keys and the same `{{placeholders}}` is a unit test (`packages/i18n/src/index.test.ts`).
- Sentences built by concatenating translated pieces; use one key with `{{placeholders}}`.
- Numbers, dates and plurals formatted by hand where i18next or `Intl` should do it.

Not user-facing, so not reported: log messages, error messages for developers, API error
messages (the contract's English messages), test names.
