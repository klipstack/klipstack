---
name: i18n
description: User-facing text exists in English and Spanish, never hard-coded
severity-default: medium
---

Klipstack's interface is in English and Spanish (`packages/i18n/src/locales/{en,es}`). Report:

- Text a user can see or hear (labels, buttons, headings, messages, placeholders, `aria-label`,
  `title`, `alt`, page titles, emails) written as a literal in a component or route instead of a
  translation key.
- A key added, renamed or removed in one language but not the other. The Spanish must be
  Spanish: not a copy of the English, not a placeholder.
- Sentences built by concatenating translated pieces; use one key with `{{placeholders}}`.
- Numbers, dates and plurals formatted by hand where i18next or `Intl` should do it.

Not user-facing, so not reported: log messages, error messages for developers, API error
messages (the contract's English messages), test names.
